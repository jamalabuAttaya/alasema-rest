المشروع الكامل بعد تعديل الشعار والهيرو والسبلاش وواتساب

التطبيق داخل مشروعك المرتبط بـ GitHub:
1. احتفظ بنسخة احتياطية من مشروعك.
2. انسخ محتويات هذا المجلد (وليس المجلد نفسه) إلى جذر مشروعك، حيث يوجد package.json.
3. وافق على دمج المجلدات واستبدال الملفات المطابقة. احتفظ بمجلد .git الموجود عندك.
4. نفذ npm ci ثم npm run check ثم npm run dev.
5. راجع النتيجة محلياً، ثم نفذ أوامر Git عند رغبتك في رفع التعديلات.

الشعار والصورة محفوظان بصيغة JPG الأصلية دون تغيير الرسم أو الألوان.
تظهر صورة الهيرو كاملة مع النص أسفلها لتجنب القص على الهواتف.
السبلاش يظهر لمدة 8 ثوانٍ مرة واحدة في الجلسة ويمكن تخطيه.
تستخدم روابط واتساب الرقم 972594804807، مع إبقاء المكالمات على +970594804807.
بصمة CSP محدثة ومتوافقة مع بيانات الصور في index.html.
لا تتضمن الحزمة node_modules أو dist أو .git؛ يتم إنشاء ملفات التثبيت والبناء بالأوامر أعلاه.

## استبدال النسخة

احتفظ بنسخة احتياطية، ثم انسخ محتويات مجلد alasema-rest إلى مجلد مشروعك مع استبدال الملفات المتطابقة. احتفظ بمجلد .git إن كنت تعمل على مستودع قائم. الحزمة لا تشمل node_modules؛ نفّذ `npm ci` ثم `npm run check` و`npm run dev`.

لفحص السبلاش من جديد، افتح الموقع في نافذة خاصة. لا يتضمن هذا التسليم أي نشر أو تعديل للمستودع البعيد.

## نطاق التحقق

نجحت فحوص ESLint وبيانات القائمة وبناء الإنتاج، وفحص توافق سياسة CSP وملفات المصدر والإنتاج. لا يتضمن بناء الإنتاج ملفات خرائط المصدر.

تعذر تشغيل اختبار المتصفح الآلي بسبب عدم توفر متصفح صالح للتشغيل في بيئة الفحص. راجع العرض على الهاتف والتابلت والحاسوب قبل النشر، خصوصًا القائمة العلوية والنوافذ المنبثقة والاتجاهين العربي والإنجليزي. لا تمثل فحوص البناء ضمانًا لخلو الموقع من جميع الأخطاء.

موقع مطعم متجاوب مبني باستخدام React وVite، ويضم صفحات الرئيسية، قائمة الطعام، عن المطعم، المعرض والتواصل.

## المتطلبات

- Node.js 20.19.0 أو أحدث
- npm 10 أو أحدث

## التشغيل

```bash
npm install
npm run dev
```

## التحقق والإنتاج

```bash
npm run check
npm run build
npm run preview
```

ينفذ أمر `npm run check` فحص الشيفرة، والتحقق من تطابق بيانات قائمة الطعام العربية والإنجليزية، ثم إنشاء نسخة الإنتاج.

## إعدادات النشر

- إعدادات Vercel وترويسات الحماية موجودة في `vercel.json`.
- إعدادات Netlify الاحتياطية موجودة في `public/_headers`.
- ملفات الفهرسة موجودة في `public/robots.txt` و`public/sitemap.xml`.
- بيانات المطعم المنظمة موجودة داخل `index.html`.
